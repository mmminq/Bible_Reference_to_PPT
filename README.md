<h1>Bible Reference to PPT</h1>

성경 구절 목록을 리스트 형태로 입력하면 사전에 제작된 템플릿을 기반으로 성경 구절 주소, 본문이 입력된 PPT 파일을 제작할 수 있습니다.

Description:<br>
개역개정-text: 개역개정 성경 텍스트 파일입니다.

ESV-text: ESV 성경 텍스트 파일입니다.

main.py: 프로그램을 실행하기 위한 코드입니다.

pptx_generator.py: PPTX 파일 편집을 위한 코드입니다.

verse_loader.py: 구절 주소 목록을 입력받아 한영 구절을 반환하는 코드입니다.

template.pptx: 구절 입력을 위한 pptx 템플릿입니다. 템플릿 수정 시 코드도 수정이 필요합니다.


How to use<br>
Zip 파일 형태로 그대로 다운받은 다음 'main.py' 파일을 실행하시면 됩니다.
